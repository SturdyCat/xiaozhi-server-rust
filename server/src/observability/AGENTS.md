# 可观测指引

继承[服务端指引](<../../AGENTS.md>)。进程内观测态：令牌用量计量、延迟 / 事件聚合大盘、统一时间格式、事件总线。设备 / 会话 / 最近对话 / 用量 / 延迟均为进程内态，重启清零；长期对话由记忆原文表留存。

- 分段延迟指标见[TTFA 指标](<metrics/AGENTS.md>)：被动采集、事件聚合 P50/P90/P95/P99；`/api/metrics` 只增不改（老字段不变），新增排队等待节只追加。
- 事件总线 `events.rs`：负载 + 共享记录器，变体与字段命名单一权威在此。
- 用量计量 `usage.rs`：令牌用量。
- 时间格式 `logtime.rs`：控制台 fmt 与 `/api/logs` 日志流共用的唯一时间出口（本地化时间戳）。
