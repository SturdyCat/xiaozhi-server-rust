# 音色目录探测

[voices](<../voices.rs>)通过真实合成 API 验证候选池，只有成功项进入目录，目录持久化缓存；候选名称不代表账号实际获授权。

- 平台并发限流会造成假阴性；保持低并发（现有 2）与有限重试，不为“更快”调成高并发。
- refresh 是后台长任务，管理台轮询 probing 后重拉；探测失败必须可见，不能静默清空上次可用目录。
- 留空测试凭据逐项回落已保存凭据，GET 仍不得泄漏密钥。
- 探测保持独立限流，不与生产 ASR/TTS 闸门混用；统一插件 actions/job 尚为设计，不擅自替换既有端点。
